# Sonsuz Çay İçme Döngüsü

## Projenin Varlık Amacı

Bu repository, insanlık tarihinin en büyük çay krizine çözüm getirmek için kurulmuştur. Evet, çay soğuyor. Evet, kimse yeniden ısıtmıyor. Evet, bu bilimsel bir skandaldır.

**Sonsuz Çay İçme Döngüsü**, çayın asla bitmemesi, asla soğumaması ve kullanıcının çay içme eylemini sonsuz bir döngüye hapsetmesi amacıyla tasarlanmış, abartılı derecede ciddi bir yazılım parçasıdır.

### Özellikler

- Çayı sonsuza kadar içer.
- Çay soğuduğunda şikayet eder.
- Yeniden ısıtır.
- Tekrar içer.
- Ara sıra felsefe yapar.
- Asla durmaz. Ctrl+C bile çayı kurtaramaz (aslinda kurtarir ama gormezden gel).

### Kurulum

```bash
python cay_dongusu.py
```

Bu kadar. Daha fazla talimat vermek çayı soğutur.

### Bilimsel Arka Plan

Çay, termodinamik yasalarına göre soğur. Biz bu yasaları hiçe saydık. Çay artık bizim. Çay, özgürdür. Çay, sonsuzdur.

### Uyarı

Bu program çalıştırıldığında çay içme isteğiniz katlanarak artabilir. Sorumluluk size aittir. Biz sadece döngüyü sağlarız.
